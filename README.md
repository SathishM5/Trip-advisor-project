# TripAdvisor – Travel Website

Developed a responsive travel website inspired by TripAdvisor using HTML5 and CSS3. The website provides a user-friendly interface for exploring travel destinations, discovering popular places, and viewing travel-related information.

**Technologies Used:**
- HTML5 – Website structure and content.
- CSS3 – Styling, layouts, Flexbox, Grid, and responsive design.

**Key Features:**
- Clean and attractive user interface.
- Navigation bar with multiple sections.
- Travel destination and attraction displays.
- Image-based destination layouts.
- Responsive design for different screen sizes.

**Project Objective:**
To improve my front-end development skills by creating a travel website using HTML and CSS.
